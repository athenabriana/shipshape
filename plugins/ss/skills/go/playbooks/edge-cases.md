# edge-cases

Map the edge cases of a behavior: before coding as acceptance criteria, or on a diff as the cases it misses.

## Steps

1. Run `edge-cases` in plan mode on a planned behavior, a brief or a feature description, or in diff mode on a branch, a diff, a PR or a function.

## Route

None: plan mode writes criteria and diff mode reads, so there is no change to size.

## Endpoint

None: read only. Plan mode writes its WHEN/THEN table where the caller says (a brief, a front doc, a PR body), or in the chat when nobody says.
