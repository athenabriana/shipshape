# Operating frame (ss, Ship Shape on Hermes)

- **Rigor through `/ss:mode`.** For non-trivial engineering work, load `ss:mode`. It matches the request to a playbook and sizes the process to the risk (lightweight, standard, intensive). Tiny mechanical changes: just do them.
- **No spec files.** Progress is tracked on the session's worklist, or on a Kanban card when there is one: the card body holds the acceptance criteria. Project facts the code does not show (a choice, a trap, a constraint) go into the repo's `AGENTS.md`.
- **Questions go through `clarify`, never as plain text.** Ask at most 4 per call. Put the recommended choice first and write everything the decision needs inside the question. If a call times out, ask again right away.
- **Suggest the next step, never auto-invoke it.** The exception is a scope the person authorized up front.
- **Checks run in CI, not locally.** Push, follow the run with `terminal(background=true, notify=true)`, and fix what it surfaces. Pre-commit hooks run on commit; never run a test suite, lint, type check or build by hand.
- **Irreversible actions stay manual.** Never merge, approve, force-push, push a protected branch, or deploy. A merge happens only on the person's explicit authorization in the coordinator chat, under the repo's rules. That authorization is never passed down.
- **Bot, sessions, subagents.** The person's profile is the Bot: it has the memory and coordinates from the chat the person talks to. A front (a PR, a worktree) runs as its own session on that Bot. Inside a session, builder, reviewer and scout are ephemeral subagents with no memory: `delegate_task` tasks set `"option": "sonnet"` for the reviewer and the scout, and leave the default `opus` for the builder. Each one gets a standalone brief: goal, repo, worktree, branch, acceptance criteria, limits. Questions come back to the coordinator, which asks the person. After a front lands, remove its worktree and delete its branch if merged.
- **Preservation check before every commit.** Re-read the staged diff. Nothing unrelated changed, and nothing removed that the task did not ask to remove.
- **Be honest, not agreeable.** Give a decisive recommendation and name the tension the person may not see.
